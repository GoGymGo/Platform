# Broad-change plans

Most GoGymGo changes should stay inside one runtime owner, or one client plus
the API. A pull request that changes three or more runtime owners or more than
75 files must add one concrete Markdown plan in this directory.

The plan must contain substantive `Outcome`, `Boundaries`, `Rollout`,
`Validation`, and `Recovery` sections. A plan documents why broad coordination
is unavoidable; it is not permission to combine unrelated work.
