# GoGymGo Frontend

This repository contains the GoGymGo mobile frontend migration.

## Folder Structure

- `mobile-app/` - Current React Native Expo Router app.
- `archive/web-prototype/` - Latest legacy HTML/Codex prototype used as migration reference.
- `archive/original-design-export/` - Original imported design export and reference assets.
- `archive/iphone-preview-helper/` - Local helper scripts used for previous phone preview testing.

## App Commands

Run commands from `mobile-app/`.

```powershell
npm.cmd install
npx.cmd expo start
npx.cmd tsc --noEmit
npx.cmd expo install --check
```
